# Retail Sales Analytics Dashboard

A static, responsive dashboard generated from the Retail Sales Analytics Jupyter Notebook.

## Publish with GitHub Pages

1. Create a **public** GitHub repository named `retail-sales-analytics`.
2. Upload `index.html` from this folder to the repository's top level (root).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then click **Save**.
6. Wait for the deployment to finish. The site URL will be:

   `https://YOUR-GITHUB-USERNAME.github.io/retail-sales-analytics/`

GitHub Pages may take several minutes to publish the first deployment.
